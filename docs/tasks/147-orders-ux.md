# 지난 KIS 주문 조회 화면

[이슈 #147](https://github.com/krdn/gon-stock03/issues/147) · [Gemini Neon과 검토한 설계](https://github.com/krdn/gon-stock03/issues/143#issuecomment-7033850718) · [선행 PR #146](https://github.com/krdn/gon-stock03/pull/146)

주문·체결에서 ‘지난 KIS 실행 기록’을 열면 종목·상태·방향·주문가격·체결과 잔량·주문별 KIS 확인 시각이 먼저 보인다. 주문 상세에서 주문일, 요청 생성 시각, 앱 요청 ID, 증권사 주문번호와 출처를 확인한다. 식별자와 출처는 복사할 수 있다. 로컬 읽기 시각과 미제공 항목은 목록 아래 ‘원장 정보’에 있다.

- 재개용 주소는 `/orders?view=history`다. 보기와 상태 필터는 뒤로가기·새로고침 후 복원한다. 검색은 종목·주문일·식별자를 지원하며 입력 원문은 URL에 담지 않는다. 식별자로 찾은 기록은 상세를 펼친다.
- 정상 환경 상태는 한 줄로 요약한다. 원장 오류와 부분 실패, 미확인, 이전 데이터 및 긴급정지 경고를 유지한다. 지난 실행 화면은 로컬 원장 조회만 한다.
- 선행 버전에서 모바일 390×844 첫 주문은 1,054px, 확인 시각은 1,271px에 있었다. 변경 후 격리된 예시 화면에서 첫 주문 365px, 확인 시각 459px, 첫 행 끝 531px였다. PC 1440×900에서는 첫 행이 402~478px에 보였다. [모바일 캡처](../verification/assets/147-orders/mobile.png) · [PC 캡처](../verification/assets/147-orders/desktop.png)
- 주문 관련 Chromium 회귀 15건에서 조회 범위 전환, 오래된 응답, 복구 링크, 보기·상태 복원, 식별자 검색·복사, 조건 지우기, 0건과 부분 실패, Enter·Space로 주문 상세 열기·닫기, 오류 표시와 거래 전송 0건을 확인했다. 사용자 체감 시간은 미측정이다.
- 배포 전후 실제 화면, 외부 검토, PR·CI와 수용 상태는 [#147](https://github.com/krdn/gon-stock03/issues/147)에서 확인한다. 지도 제공과 실제 원장 관리는 각각 #143·#145의 기록을 따른다.

초기 변경에서 로컬 전체 브라우저 180건, 단위/API 276건과 프로덕션 빌드가 통과했다. 로컬 단위 검사의 데이터 인벤토리 포트는 사용 중인 지도 서버와 겹쳐 그 검사만 임시 포트에서 실행했다. 원래 포트 검사는 원격 CI 결과로 대조한다. 수정 후에는 주문·관련 통합 15건, 추가한 실시간 갱신 분리를 포함한 주문 9건을 통과했다.

Gemini Neon 최초 검토는 FAIL이었다. 이전 데이터를 표시하는 오류 상태의 조건 초기화, 모바일 상세 버튼 배치, 현재 실시간 대조가 과거 목록을 재조회하는 문제, 기본 상세 요소의 펼침 동기화를 수정했다. 같은 모델 수정분 검토는 PASS였다. CLI 초기화 모델은 두 번 모두 `gemini-4-neon-high`였고 서버 내부 모델·강도는 별도 미확인이다.

# #116 KIS 모의 매매 페이지 잔량 취소

`/paper`의 ‘미체결 잔량 취소’에서 서버가 지정한 한정 검증 원주문의 종목·번호·체결·잔량을 확인한다. ‘잔량 전부 취소’ → ‘잔량 취소 요청’을 누르면 서버가 REST 대조를 먼저 수행한다. 이미 전량 체결됐거나 미확정이면 취소를 중단한다. 실제 요청 전 SQLite에 한 번의 시도를 기록한다. 취소 ACK 직후에는 불명을 유지하며, 화면이 계좌·주문을 다시 조회해 체결·취소확인·잔량을 표시한다. 대조 실패 시 ‘취소 결과 조회’로 읽기만 재시도한다.

**적용 범위.** `cancelProbe: true`로 승인된 당일 지정가 매수의 고정 원장에 적용한다. 승인 수량은 아래 수량 설정 절을 따른다. 승인 ID, 종목·금액, 접수 후 120초, 정규장 경계와 영구 1회 시도를 재검사한다. 계좌 일반 모드에서 주문내역의 취소 결과 조회를 사용할 수 있다. 주문내역에 취소확인수량이 없으면 ‘미제공’으로 표시한다.

11월 19일 KIS 명세를 확인했다. 전량취소 TR은 모의를 제공한다. KIS가 요구하는 취소가능수량 선행 조회의 모의 TR은 미지원이다. 11월 16일의 1주 한정 API 실증은 일반 주문에 대한 면제 근거가 아니다. 최초 검증 당시에는 1주 승인만 지원했다. 당시 요청한 136,300원 하한가 2주 신규 주문은 전송하지 않았다. [KIS 정정취소](https://apiportal.koreainvestment.com/api/apis/public/detail?accessUrl=/uapi/domestic-stock/v1/trading/order-rvsecncl) · [취소가능수량 조회](https://apiportal.koreainvestment.com/api/apis/public/detail?accessUrl=/uapi/domestic-stock/v1/trading/inquire-psbl-rvsecncl)

**검증.** 브라우저에서 확인창 철회·취소 요청·전량 체결 선행·조회 실패·일반 모드의 조회 전용 동작을 검사했다. 390px의 실제 페이지와 제품 HTTP 서버를 가짜 KIS 전송기에 연결하고 승인 원주문 1주의 취소 요청 1회, REST 체결 0·취소확인 1·잔량 0, 최종 원장 cancelled를 확인했다. 실제 KIS 취소 실증은 이번 검사 범위 밖이다.

11월 19일 실행 중인 `http://127.0.0.1:4303/paper`에 기능을 적용했다. 일반 모드에서 ‘잔량 전부 취소’가 비활성임을 확인하고 ‘취소 결과 조회’를 직접 눌렀다. 실제 KIS 당일 삼성전자 두 주문은 각각 체결 2주·잔량 0주·취소확인 0주였다. 계좌 보유 8주, 이 실행기의 로컬 원장 0건이다. 실제 주문 POST 0회·취소 POST 0회. 기존 실행 폴더의 별도 변경과 원장을 보존했다.

## 주문당 수량 설정 · 11월 19일

`/paper` → **KIS 모의 수동 주문 한도** → **주문당 수량 상한 (주)** → **수량 한도 저장**. 4303에서 현재값을 5주로 저장하고 새로고침·상태 API에서 5주를 확인했다. 1~100,000주 범위의 정수로 수정할 수 있으며 5주보다 큰 값도 저장된다. 설정은 해당 서버 원장의 수동 주문에 적용하며 저장 시 주문·취소는 발생하지 않는다.

한정 지정가 승인서는 선택 필드 `maxQty`를 지원한다. 화면은 저장 수량과 별도 1회 승인 수량 중 작은 값을 주문 입력 상한으로 사용한다. 승인 원장은 승인 당시 값을 고정하며 이전 형식 또는 수량 미지정 승인은 1주다. 승인 총액은 **단가 × 전체 주문 수량**으로 검사하며 시장가 1주, 저장 전략 계약, 독립 #107 실행기 조건은 별도로 처리한다. 한도를 낮춰도 이미 접수한 원주문의 잔량 취소는 승인 원주문 기준으로 가능하다.

**하한가 재시험.** 별도 1회 원장·서버에서 동일한 `/paper`로 1주를 제출했다. 12:16:18 KST 앱이 지정가 136,300원과 재조회 현재가 190,700원의 불일치를 확인하고 HTTP 400으로 차단했다. 실제 주문·취소 POST 각 0회, 전용 원장 주문 0건, 계좌 보유 8주·미체결 0건. 한정 지정가 주문에는 현재가 일치 검사가 적용된다. 수량을 변경해도 이 조건은 유지된다.

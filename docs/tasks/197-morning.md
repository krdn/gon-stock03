# 장전 포트폴리오 운용

[기준 이슈](https://github.com/krdn/gon-stock03/issues/197). 국내 주식·ETF 전체를 대상으로 장전 근거, 기존 보유, 일봉과 자금 한도를 대조한다. 첫 화면은 판단·이유·중단 조건, 상세는 원문과 공개 시각을 담는다.

당일 승인 없는 매수와 추가 매수를 보류한다. 신규 편입은 별도 승인하고 손실 도달 후 매수 중단은 당일 유지한다. 전날 승인한 매도 조건만 이월한다. 반복 매매와 보유의 비용 차감 성과 및 매수 중단 정책의 미사용 기간 성과를 비교한다. 데이터 부족은 미측정으로 남긴다.

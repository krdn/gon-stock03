# 장전 포트폴리오 운용

[기준 이슈](https://github.com/krdn/gon-stock03/issues/197). 국내 주식·ETF 전체를 대상으로 장전 근거, 기존 보유, 일봉과 자금 한도를 대조한다. 첫 화면은 판단·이유·중단 조건, 상세는 원문과 공개 시각을 담는다.

당일 승인 없는 매수와 추가 매수를 보류한다. 신규 편입은 별도 승인하고 손실 도달 후 매수 중단은 당일 유지한다. 전날 승인한 매도 조건만 이월한다. 반복 매매와 보유의 비용 차감 성과 및 매수 중단 정책의 미사용 기간 성과를 비교한다. 데이터 부족은 미측정으로 남긴다.

## 운용

KIS 모의 포트폴리오에서 **시장 전체 일봉 수집 → 운용 계획 보기 → 오늘 모의 운용 승인** 순서로 사용한다. 이 화면과 대시보드의 승인 버튼은 같은 계좌·날짜·보고서 ID를 사용한다. 자동 자료 수집은 기존 실시간 개발 실행 환경에 `STOCK_MORNING_REPORT=1`을 설정한 프로세스에서만 동작한다. KIS 접속키와 HTS ID, 당일 확인한 KRX 세션은 기존 실시간 실행 지침을 따른다. 외부 스케줄 등록은 필요 없다. 전용 1회 주문 및 단일 전략 계약 프로세스는 포트폴리오 운용에서 제외한다.

장전 스캐너는 KOSPI·KOSDAQ의 공식 주식·ETF 목록을 순회한다. KODEX 200의 관측 거래일과 최근 종목별 원시 일봉을 대조한다. 거래정지, 상장 기간 부족, 누락 또는 수집 시한 초과 종목은 유효 표본에서 제외한다. 전 시장을 구독하지 않는다. 1차 후보와 이월 종목을 먼저 포함하고 장중 감시 슬롯은 최대 18개다. 최근 고점·거래량으로 새 후보를 최대 5개 선택한다. 20거래일 고점, 5거래일 저점, 1주 주문, 미국 주가 하락과 원화 약세 동시 발생 시 신규 배분 절반은 모의 운용 가설이다. 공개 자료 제목·요약·시각과 원문 링크를 보존한다. 개별 분석가의 유료 원문 및 의견 합의율은 미측정이다.

모의 실행은 당일 계획 승인, 실시간 종목 구독 확인, REST 대조, 계좌 위험·수량·투자 한도를 적용한다. 새로운 장중 제안은 별도로 승인한 뒤 다음 유효 교차에서 매매한다. 이월은 장후 보유 수량과 매도 조건을 확인해 다음 거래일에만 적용한다. 공식 세션 설정과 KODEX 200의 직전 거래일로 이월 대상을 연결한다. 연결 중단이나 긴급정지 후 상태를 확인하고 명시적으로 감시를 재개한다. 전송 여부가 불명확한 주문은 기존 원장에서 대조한다.

## 연구와 장후 대조

장후 결과는 장전 보유 수량에 당일 종가를 적용한 보유 유지 평가액과 장후 계좌 평가액을 비교한다. 입출금과 별도 주문이 섞이면 자동매매 기여도는 미측정이다. 과거 보고서는 날짜 선택으로 조회한다.

`node --import tsx scripts/morning-replay.ts 관측자료.json`은 고정·변동성 연동·중단 없음·보유 유지의 비용 차감 수익과 낙폭을 계산한다. 입력은 출처 `source`, 편도 비용 `feeBps`와 `slippageBps`, 미사용 기간 시작일 `testFrom`, 시간순 `days`다. 거래일마다 `date, cash, holdings, open, close, events`가 필요하다. 종목별 가격과 수량은 종목코드를 키로 쓴다. 이벤트의 `signalAt`은 실행 가능 가격 시각 `at`보다 빨라야 하며 `code, price, side, qty`를 함께 보존한다. 비교 단위는 같은 아침 포트폴리오에서 시작한 거래일별 실험이다.

검토한 실제 자료 파일을 서버의 `STOCK_MORNING_REPLAY`로 지정하면 당일 이후 표본을 제외하도록 검사한다. 학습·미사용 기간이 각각 60거래일 이상일 때 5거래일 단위 짝비교와 최대 낙폭을 확인한다. 선택 근거가 부족하면 기존 계좌 한도를 유지한다. 이 표본 길이와 통계 기준도 연구 가정이며, 운영 수익률·최적 중단값은 미측정이다.

## 검증 기록

- 11월 22일 격리 서버에서 실제 공개 피드로 보고서를 생성하고 같은 ID를 재조회했다. 기준 시각 이전 항목 26건이었고, DART·한국은행의 현재 피드에는 해당 항목이 없었다. 같은 날 FRED에서 미국 지수·국채금리·원달러 환율의 최근 관측일을 확인했다.
- 공식 KIS 모의 조회로 KODEX 200의 10월 1일~11월 20일 일봉 35개를 확인했다. 구성비 전체 응답 검증은 미확인이고 재조회에 호출 제한이 관측됐다. ETF 정보 부족, 승인 전 신호, 승인 후 모의 어댑터, 이월 매도 수량과 중단 조건은 격리 검증했다.
- 지정 모델 Claude Opus 5.5/high의 독립 리뷰에서 승인 복구·자료 시각·구독 한도·예산 복구·이월 조건을 지적받아 수정했다. 새 주문의 실제 KIS 접수·체결, 다음 거래일 연속 운용, 통계적으로 유리한 매수 중단값과 순수익은 미측정이다.

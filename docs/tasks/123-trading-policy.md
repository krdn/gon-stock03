새 정책은 설정 화면이 발행한 파일에서만 기동한다. 일반 위험 한도와 계약 상한 중 실제 주문에 더 작은 한도가 적용된다. 가격대가 다른 지정가의 호가는 종목 유형과 지정가 금액으로 계산한다. 원장 바인딩·종목 지문·REST 필요 검사는 화면에서 풀 수 없다. 아래는 이번 제품 확장의 기준이 된 첫 격리 검증 기록이다.

**제품 검증.** 실제 390px·1440px 브라우저에서 하한가 2주 및 지연 전략을 각각 저장·고정하고 재개한 파일 조건과 일치함을 확인했다. 고정 단계 브로커 호출 0회였다. fake transport에서 16:05 하한가 2주 전송, 다주 시장가 매수·매도, 상한가 기준 예산 초과 거부, 원 신호·시세 각각 만료, 응답 불명·재시작을 검사했다. 실제 KIS 모의 주문·취소·전략 전송은 각 0회다.

**리뷰.** 설계와 수정분은 `claude-opus-5-5`/high로 요청했고 두 응답 모두 success이며 `modelUsage`의 모델명이 일치했다. 서버 내부 effort는 독립 확인하지 못했다. 새 마스터 종목의 구형 계약 경로를 차단했고, 시장가/실행일 변경 시 숨은 가격·날짜 조건을 없애는 브라우저 회귀를 확인했다. 수정분 리뷰가 추가로 지적한 KIS 요청창 만료는 SQLite 트랜잭션 안에서 검사한다. 요청창과 REST 시세 각각을 전송 직전 만료시킨 회귀에서 예약 1회 유지, dispatched=0, 주문 POST 0회를 확인했다.

**현재가 변동 재현.** 14:59 KODEX 200 사전검사에서 최초 79,835원과 재조회 79,830원이 달라 기존 현재가 일치 주문이 차단됐다. 새 한정 매수에서 ‘재조회 현재가로 매수 · 단가 상한 지정’을 선택하면, 확인한 상한 이하에서 서버가 조회한 단가를 매수가능 조회·주문·원장에 동일하게 사용한다. 80,000원 상한의 2주 예시는 최대 160,000원이고 실제 전송 단가가 79,830원이면 주문대금은 159,660원이다. 상한 초과 시 전송 0회, 같은 ID 재호출은 기존 접수 결과를 반환한다. [실제 실패 및 관측](../verification/2026-11-19-strategy.md#1452-실제-부분체결과-1459-현재가-변동)

해당 수정의 Opus 설계·구현 리뷰는 `claude-opus-5-5` / high로 요청했고, 응답은 success·동일 modelUsage로 차단 결함 없음이었다. 리뷰에서 미확인한 제품 HTTP 경로로 최소실행 계약의 상한 정책을 읽고 주문 요청을 제출해 단가 79,830원·상한 80,000원·가짜 POST 1회를 확인했다. 기존 소진 원장을 승인 없이 다시 여는 경로는 계속 차단한다.

## 136,300원 주문이 갈리는 지점

11월 19일 12:16 KST 기존 한정 앱에서 삼성전자 하한가 136,300원 1주를 입력했다. 재조회 현재가 190,700원, HTTP 400, 실제 주문·취소 POST 각 0회, 최종 보유 8주·미체결 0건이었다. 앞선 2주 미전송과 별개다. `PaperBroker.submit`은 승인 범위·시간창 확인 → SQLite의 1회 소진 → 잔고·당일 주문 대조 → 신선한 KRX 시세 조회 → 승인 가격 검사 순으로 진행한다. 당시 차단은 미수 없는 매수가능 조회와 원장 sending 저장보다 앞이었다. ## #25와의 연결

정상 전략 2주 접수·전량 체결은 이미 관측했다. 이번 재현 수량 1주에서는 부분체결이 불가능하며, 136,300원 2주는 272,600원으로 기존 지정가 상한 20만원을 초과한다. 하한가 허용 자체가 체결이나 경합을 보장하지 않는다. #25는 실제 일부 체결·양수 잔량 → 같은 주문의 잔량 취소 시도 시각 → 최종 체결·취소확인·잔량 대조가 남았다. 취소 전에 추가 체결되거나 취소가 거절된 경우도 같은 주문의 실제 응답으로 남겨야 한다. 0주 체결 전량 취소·즉시 전량 체결·가짜 접수는 이 항목에 포함하지 않았다. [#25 재개 조건](25-validation.md#다음-정규장-재개)

다음 운영 도입 단계에는 고정 파일·원장·화면에서 동일한 단가·정책·세션을 표시하고 검증하는 작업이 필요하다. 이번 작업에서 실제 모의 주문·취소·전략 전송은 각각 0회였다. #25 실증은 이 탭에서 새 계약의 일자·시간·종목·수량·가격·금액·시도 횟수와 모바일 취소 주체를 확정한 뒤 진행할 수 있다.

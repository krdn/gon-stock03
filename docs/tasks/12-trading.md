종목 응답·날짜·가격 검증, 전환 경합·실패·오래됨·숨김탭 회귀, 기존 DEMO 흐름을 검증한다. 현재 서버는 인증값 누락이며 Infisical dev/kis 읽기는 성공했다. 같은 원장을 보존해 시세 조회용 인증값을 주입한다. 실제 주문·취소·전략·WS 구독은 하지 않는다.

결과: [실제 응답과 검증](../verification/2026-11-17-trade-live.md). 단위216·브라우저150·빌드 PASS. 실제 KIS 현재가189,800원·일봉100건 수신과4303 화면 일치 확인. 실행 경로는 현재 작업 폴더이며 동일 SQLite 백업·보존 후 Infisical 주입으로 재시작했다. 실제 계좌조회·주문·취소는 하지 않았다. 원격 CI·리뷰 결과는 PR90에 연결한다.

# 매매 설정과 다음 실행 고정

[설계 연구](../research/trading-settings-navigation.md) · [Opus 5.5 설계 판정](https://github.com/krdn/gon-stock03/issues/120#issuecomment-6999028213) · [구현 #122](https://github.com/krdn/gon-stock03/issues/122).

| 화면 | 저장 결과 |
|---|---|
| `/settings/trading` | 일반 주문·위험, 다음 한정 실행, 다음 전략 계약의 요약과 링크 |
| `/settings/trading/general` | KIS 수동 주문 수량과 DEMO·KIS 공통 주문당 금액·종목별 투자금·일일 손실을 일반 원장에 저장. 주문 화면의 ‘수량 한도 변경’에서 진입하면 종목·가격·수량·방향을 유지해 돌아간다. 긴급정지는 `/risk` |
| `/settings/trading/once` | 실행일, 종목, 지정가/시장가, 수량·금액, 기존 보유 허용 및 한정 잔량취소 조건 |
| `/settings/trading/strategy` | 저장 KIS 전략/revision을 선택하고 기간(KST)·주문당 금액·총 시도·누적액·매도 범위를 설정. 종목·교차 주기·수량은 선택한 전략에서 가져온다 |

**다음 실행 준비.** ‘대상·기간’ → ‘한도·조건’ → ‘초안 저장 및 검토’ → ‘다음 실행 고정’. 편집 중 입력은 해당 탭의 세션 저장소에, 검토 단계의 저장본은 일반 서버 SQLite에 있다. 서버는 오래된 초안 버전, 변경된 전략 revision, 거래시간과 겹치지 않는 기간을 검사한다. 공통 위험 한도·수량과 전략 설정을 새 원장에 복사한다. 전용 모드에서는 현재 실행 조건·전략 사용량을 확인하고 공개 조건을 복사해 일반 앱에 가져올 수 있다. 기존 계약과 소진 이력은 새 초안을 저장해도 보존된다.

**명시적 기동.** 고정 완료 화면에 일반 원장 폴더를 기준으로 한 파일 경로가 표시된다. 예를 들어 일반 원장이 `.local/workspace.sqlite`이면 파일은 `.local/trading-runs/` 아래에 있다. 별도 터미널/포트에서 동일 모의계좌의 인증 설정을 주입하고 파일 하나를 지정해 `npm start`로 실행한다. 한정 실행은 `KIS_PAPER_APPROVAL_FILE`, 전략은 `KIS_STRATEGY_CONTRACT_FILE`이다. 전용 DB는 파일에서 결정한다. 명시한 `STOCK_DB`가 다른 파일이면 시작을 거부한다. 기존 JSON 환경변수와 동시 지정도 거부한다. 고정만 해서는 서버·시세 구독·전략·주문이 시작되지 않는다.

고정 파일은 0600, 생성 폴더는 0700이다. 서버가 ID를 발급하고 계좌 지문·전용 원장을 묶는다. 고정 후 원본 파일과 원장을 같은 위치에 보존해야 한다. 전략 원장의 최초 기동·재기동은 일반 원장의 저장 전략 ID·revision·종목·교차·수량도 다시 확인한다. 원장이 없거나 불일치하면 실패한다. 원본 일반 원장에도 고정 완료 기록이 있어야 하므로 해당 원장을 함께 보존한다. 위험 한도 수치와 긴급정지 상태를 복사하며 기존 계좌의 손실 기준·원장 예약 사용량은 이전하지 않는다. 같은 버전은 두 번 고정할 수 없다.

**적용 범위.** 1차 구현은 현재 서버가 집행하는 조건을 편집한다. 한정 지정가의 재조회 현재가 일치, 시세·원 신호 5초, 취소 120초, 시장가 삼성전자 1주·30만원, 지원 종목·시간과 브로커 제약은 확장하지 않았다. [정책 확장 검증 #123](https://github.com/krdn/gon-stock03/issues/123).

**검증.** 4303에서 모바일 목차와 수량 5주·공통 금액 100만원/400만원/30만원, 저장 KIS 전략 없음 상태를 직접 확인했다. 실제 계좌에는 새 초안·고정본을 만들지 않았다. 격리 원장에서는 PC/모바일 브라우저·제품 HTTP, 고정 파일을 읽는 새 서버 프로세스, 원장 경로·계좌·revision 불일치와 중복 고정을 검사했다. 진행 중 모드의 편집은 409이고 검증기의 브로커 전송은 0회였다.

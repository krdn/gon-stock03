# 설정 왕복 후 모의 주문 입력 복원

기준 이슈 https://github.com/krdn/gon-stock03/issues/154 · 상위 #149 · 매매 설정 #152. 시작 main `04434fd`, 브랜치 `krdn/ux2-154-paper-return`.

모의 주문에서 수량 한도 변경으로 이동한 뒤 설정 저장·새로고침·뒤로·앞으로·명시적 복귀 시 원래 종목·방향·수량·지정가를 복원한다. 별도 입력 이력과 전송 미확인 요청의 격리를 확인한다. 필수 자료는 [모의 매매 #14](14-paper.md), [매매 설정 #122](122-trading-settings.md), `Paper.tsx`와 `TradingSettings.tsx`의 주문 복귀 링크다.

PC 1440×900·모바일 390×844 모두 뒤로 가기에서는 `000660 / 매도 / 4 / 72500`을 유지했고, 앞으로 간 뒤 복귀 링크에서 `000660 / 매수 / 1 / 빈 가격`이 됐다. 이때 Paper가 공용 초안을 mount 시 삭제한다. 설계는 브라우저 이력별 복귀 키와 종목 일치 검사를 사용하고 새 전송과 미확인 복구는 기존 확인 절차에 둔다.

이슈: https://github.com/krdn/gon-stock03/issues/3 · 상위 #1 · 브랜치 `feat/trading-workbench`

완료 조건: 충분한 공식 조사에 기반한 전체 화면과 상세 설계실, PC/모바일 탐색 검증. 구현/검증 결과의 사용자 수용은 별도다.

- 구현: 15개 화면. 설계실 6개 주제(전체, 화면별, 구조, 주문 흐름, 단계, 출처). 단계별 요청 초안용 공용 프로젝트 지도.
- 필수 읽기: `src/specs.ts`, `docs/research/kis-2026-11.md`, `docs/verification/2026-11-14.md`.
- 검증: TypeScript/빌드, Playwright에서 15개 화면 × 1440/390 너비 탐색·가로 넘침, 설계 딥링크·주문 단계 선택.
- 미검증: 사용자 취향·디자인 수용, 브라우저 전 종류. 지도 초안은 실제 AI 전송과 미연결.
- 실패·조치: 초기 색 대비 부족을 자동 접근성 검사로 발견해 조정. 시장 표의 숨김 열 헤더 정합성 보정.
- 다음: 사용자가 설계실에서 특정 화면/흐름 피드백을 주면 같은 화면 계약을 갱신하고 해당 흐름을 재검증.
- 리뷰/검사: 독립 리뷰의 입력값 유지·초기 로드 지적 수정. 브라우저 9개 흐름, 대시보드·설계실·위험관리 접근성 위반 0.

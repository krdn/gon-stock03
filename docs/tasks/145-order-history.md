# 주문 원장 출처와 KIS 확인 시각

[이슈 #145](https://github.com/krdn/gon-stock03/issues/145) · [화면 협의 #143](https://github.com/krdn/gon-stock03/issues/143) · [원장 운영](../operations/local.md#지난-kis-실행-원장)

4303의 일반 원장은 0건이었다. 지난 실행의 KODEX 200 주문은 전용 원장에 별도로 보존됐다. 주문 화면의 로컬 읽기 시각과 증권사 확인 시각을 구분하고, 지난 실행 원장에서 근거가 있는 주문을 읽기 전용으로 열 수 있게 한다.

기존 원장은 성공한 원주문 대조·복구 확정의 증권사 관측 시각을 읽는다. 이후의 대조는 결과가 같아도 주문 식별과 수량 상태를 검증한 시각을 별도로 저장한다. 원장 파일 시간이나 조회 실패 시각을 대신 사용하지 않는다. 지난 실행은 출처별 기록을 보여주며 거래 조작을 제공하지 않는다.

검증용 전송기에서 기존 상태와 같은 주문, 다른 수량, 복구 확정, 종료된 주문의 불일치, 고정 원장 자동 연결과 등록한 이전 원장의 누락을 검사했다. 390px 화면에서 과거 행의 거래 조작 0개, 상태 전환 시 출처 분리·POST 0건을 확인했다. 로컬 전체 단위 검사와 지도 미리보기가 4328 포트를 공유해 포트 점유 실패 1건이 발생했다. 지도를 유지하면서 그 검사만 임시 포트로 이동한 전체 276건은 통과했다. 최종 관련 단위·API 90건, 주문 브라우저 7건, 타입 검사·빌드는 통과했다. 기본 포트 CI·실제 웹 검증은 이슈와 PR에 기록한다.

지정 Claude Opus 5.5/high 독립 리뷰에서 현재 원장 중복 경고, 시각 형식·정렬과 OS 소유자 확인 조건을 보완했다. 수정분 재검토는 PASS, 반환 모델은 두 번 모두 `claude-opus-5-5`였다.

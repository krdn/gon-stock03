## 리뷰 지적과 적용

- 빈 결과를 코드 형식만으로 판단하던 오류를 재현했다. 필터 밖에 코드가 있으면 다른 시장 안내, 마스터 로딩/실패면 확인 대기, 조회가 완료된 마스터에 코드가 없을 때만 미등록 안내로 나눴다. `KODEX2` 같은 이름 검색을 상장폐지 안내로 바꾸지 않는다.
- 실제 마스터에만 있는 관심코드는 저장 수를 별도로 안내하고 시장 탐색으로 연결한다. 제품 화면에 이슈 번호나 구현 일정을 넣지 않았다.
- 상세가 열리면 영역으로 포커스와 스크롤을 옮기고 닫으면 원래 버튼에 포커스를 돌려준다. 열기 전용 버튼에 토글 동작을 뜻하는 `aria-expanded`를 붙이지 않는다.
- 두 수정 전 브라우저 회귀를 실패시킨 뒤 보완했다. 수정 후 시장7·기존 workbench9, 총16개 브라우저 검사를 통과했다. 재검토에서 새로 지적한 LOW `aria-expanded` 두 속성은 제거하고 직접 확인했다. 이 속성 제거 뒤 외부 리뷰를 반복하지 않았다.
- 공유 현재가 파서는 잘못된 정지·거래량·등락률·종목코드를 거절한다. `temp_stop_yn` 또는 존재하는 거래량이 빈 문자열인 장전/장중 응답은 미확인이다. V01에서 현재가·주문 전 검사 경로를 확인해야 하며, 이 PR은 검증을 약화해 빈 값을 정상으로 간주하지 않는다.
- 마스터 플래그 오프셋은 공식 Python `field_specs` 누적 폭과 `part2_columns`를 함께 대조했다: KOSPI 60/61, KOSDAQ 55/56. 개별 종목의 정지·정리매매 사건과의 별도 대조는 미실행이다. `won`은 숫자 반올림·자리 구분만 하며 단위를 붙이지 않는다.

## 롤백 범위

`market_removed` 추가 테이블은 기존 테이블을 바꾸지 않는다. 그러나 영문 포함 관심코드를 저장한 뒤 원래 `73fa8d1`로 그대로 돌아가면 이전 클라이언트의 숫자 6자리 검증이 전체 상태를 거절한다. 원본 DB와 관심목록을 보존하고, 롤백 전에 해당 관심코드를 현재 화면에서 해제하거나 영문코드 수용·해제 호환 패치를 유지해야 한다. 자동 삭제나 실제 롤백은 실행하지 않았다.

제품 SHA의 [앱 CI](https://github.com/krdn/gon-stock03/actions/runs/43682425291)에서 단위62·브라우저40·빌드, [구성 CI](https://github.com/krdn/gon-stock03/actions/runs/43682425267) 성공을 원격 로그와 대조했다. 문서 후속 커밋의 최종 CI는 PR33에서 확인한다.

## 관측

- 기존 앱과 Infisical dev /kis의 REST 인증값·계좌가 같음을 값 비출력 비교로 확인했다. HTS ID 존재·세션 스키마 유효, 세션 날짜는 오늘과 달랐다.
- 16:46 첫 `dev:realtime` 실행은 접속키 준비 실패로 종료했다. 응답 원문이 없어 원인을 확정하지 않는다. 기본 실행으로 화면을 복구했다.
- 16:47 별도 발급 진단은 HTTP200·키 수신 성공이었다. 키는 출력·저장하지 않고 폐기했다. 이 결과를 첫 시도의 성공으로 바꾸지 않는다.
- 16:48 명시적으로 다시 실행한 `dev:realtime`은 발급 성공 후 웹4303·서버4304를 시작했다. `/proc` 환경의 존재 여부 검사에서 서버 키 있음·웹 키 없음이었다.
- `/api/state`는 `realtime.phase=stopped`, `ordersAllowed=false`, 활성 KIS 전략0이었다. 웹·상태 API 각각 HTTP200이다. 실제 구독·시세/체결통보·주문·취소는 실행하지 않았다.

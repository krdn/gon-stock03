KIS 표시값은 저장 원장이다. 로컬 읽기 완료를 최신 KIS REST 대조로 표시하지 않는다. 평균 체결가·수수료·KIS 대조 시각은 원장에 없어 미제공으로 표시한다. 원문 message·추가 evidence는 화면 계약에서 제거한다. KIS 조작은 종목코드를 유지한 `/paper` 링크로 연결하며 자동 전송하지 않는다. WebSocket은 #19, 실제 장중 수용은 #25 범위다. 사용자 직접 화면 수용은 미확인이다.

공식 자료: [React useEffect](https://react.dev/reference/react/useEffect). cleanup과 AbortController로 환경 변경·unmount 후 이전 응답 반영을 차단한다. 조사 기록은 start-context의 #13 항목에 보존했다. `gon-workflow implementation-ready .` 통과.

외부 지정 리뷰·원격 CI는 작업 파일에 기록한다. STE 기준파일 부재와 기존 번들 경고를 성공으로 바꾸지 않는다.

독립 리뷰: 중앙 기본 설정과 dry-run을 확인한 뒤 사용자 지정 `gemini-4-argon-high`/high로 직접 호출했다.

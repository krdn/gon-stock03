[통합 앱](http://127.0.0.1:4486/dashboard) · [안내 지도](http://127.0.0.1:4328/guide.html#contents) · [제품 통합 PR #187](https://github.com/krdn/gon-stock03/pull/187) · [전체 이슈 #149](https://github.com/krdn/gon-stock03/issues/149) · [Project 25](https://github.com/users/krdn/projects/25)

지도에서 궁금한 화면을 고른 뒤 **이 PC에서 예시 열기**를 누른다. 같은 카드의 **이 화면에 의견 남기기**는 해당 화면의 2차 이슈를 연다. 앱 안에서는 설계실의 화면 선택으로 같은 이슈를 찾을 수 있다. 모든 지도 카드의 예시는 이 PC의 4486 통합 앱으로 연결된다. 4303은 제품 PR #187이 반영된 실행 앱이다. 다운로드한 HTML에서 브라우저가 로컬 링크를 차단하면 설계실에서 ‘이 PC에서 검토 지도 열기’를 누르거나 예시 주소를 주소창에 붙여 넣는다.

## 검증과 수용

- **기술 검증.** 제품 18개 PR을 포함하는 커밋 [a53d8e4](https://github.com/krdn/gon-stock03/commit/a53d8e43f3d0c3c3d180da73af5de33e6496a34e). 동일 커밋의 빌드·단위/API 276건·Chromium 300건 성공. 로컬 단위 검사 한 건은 지도 서버와 포트가 겹쳐 임시 포트를 사용했다. 원격에서는 저장소의 기본 검사 그대로 실행했다. [GitHub 검사 결과](https://github.com/krdn/gon-stock03/pull/187/checks)
- **회귀 복구.** 매매일지를 포함한 중간 후보에서 291/295건이 통과했다. 저장이 차단될 때 경고·초안 보존·POST 0건을 확인하고, 503·부분 수신 뒤 새 관측으로 복구되는 fixture를 수정했다. 앞선 전략·위험·뒤로가기 결함의 재현과 수정 근거도 [작업표](../tasks/149-ui-ux-v2.md)에 연결했다.
- **화면 검증.** 1440×900·390×844 각각에서 앱 16개 화면, 설계실 6개 주제·16개 의견 대상, 지도의 실제 예시 링크 16개를 확인했다. 열람용 예시의 가격·메모·전략·주문은 합성 자료다. 실제 KIS 거래·정정·취소·전략 실행·예약과 기존 4303 원장 변경은 없었다. 실사용 체감 시간과 장중 결과는 미측정이다.
- **통합 검토.** Gemini 4 Neon High의 첫 검토는 코드 보존 증거 부족, 여러 예시 포트 혼재와 GitHub 파일 링크 문구, 최종 CI 확인 대기를 지적했다. 메인이 공용 화면 네 구간의 바이트 동일성, #180·#182·#185의 43·44·45개 조사 기록 보존, 최종 CI의 head SHA를 직접 확인했다. 지도 16개 사례를 4486으로 통일하고 로컬 지도 열기와 GitHub 파일 열기·다운로드를 분리했다. 동일 모델의 수정분 재검토는 세 항목에 제출 자료 기준 남은 재현 결함 없음이었다. 외부 모델이 CI나 파일 해시를 독립 조회한 것으로 취급하지 않는다.
- **병합 및 직접 수용.** 11월 21일 사용자 위임으로 제품 #187을 main에 병합했다. 실행 체크아웃에서 PC·모바일 모두 설계 6개 주제, 주문·체결 의견 이슈 #151, 지난 주문 3건의 확인 시각 3개, 대시보드에서 KIS 전략 환경으로 이동을 확인했다. 쓰기 요청은 0건이었다. 사용자 직접 수용은 대기 중이다.
- **기록.** 화면별 원래 문제, 판단과 이견, 전후 캡처, Gemini 검토 결과와 개별 한계는 [작업표](../tasks/149-ui-ux-v2.md)와 위 이슈에 있다. 지도는 [PR #144](https://github.com/krdn/gon-stock03/pull/144), 진행·수용 기록은 [PR #153](https://github.com/krdn/gon-stock03/pull/153)에서 관리한다. Gemini는 CLI 초기화 모델을 확인했고 공급자 내부 실제 모델과 추론 강도는 별도 미확인이다.

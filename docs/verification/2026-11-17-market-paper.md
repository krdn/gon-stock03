## 새 실행 승인과 시간창 종료

사용자는 첫 실행 종료 후 같은 종목·수량·금액의 새 한정 실행을 허용했다. 안내한 조건은15:28 이전 시작 여유 확보였다.
답변 확인 시각은15:28:16 KST였다. 마감 조건을 넘겼으므로 새 실행ID·서버·주문을 만들지 않았다.

새 실행 허용 범위는 보존한다. 다음 장중 수동 시작 때 날짜·시간창·계좌·미체결·보유·모바일 취소 조건을 다시 확인한다.
예약·자동 시작·반복 주문은 설정하지 않았다. 같은 금액·수량 승인 자체를 다시 요청하지 않는다.

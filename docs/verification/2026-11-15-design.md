## 재현·수정·한계

- 기존 선택 버튼에 접근성 선택 상태가 없고, 미등록 주제 URL은 내용이 비었다. 선택 상태·기본 주제 복구를 추가했다. 비정수·음수·무한대 단계 URL도 기본 단계로 복구한다.
- 모바일 키보드로 전략 스튜디오를 선택할 때 버튼 오른쪽453px이 화면390px 밖으로 나갔다. 포커스 및 상세 링크 선택 시 버튼을 보이게 했다. 새로고침의 native 스크롤은 0.3125px 반올림 차이를 보여, 추가 검사의 viewport 비율을 1에서0.99로 조정하고 전체 67개를 다시 통과했다.
- 중간 집중 검사가 이전 `dist`를 읽어 같은 실패를 반복했다. 새 빌드 후 검증했다. 첫 전체67 PASS 후 상세 링크 노출을 추가했고, 위 반올림 검사 실패를 보정한 최종 전체67 PASS를 별도 확인했다.
- 별도 화면 확인 서버 종료 후 캡처 시도는 연결 실패였다. 다시 띄운 자격값 없는 서버에서 정상 화면을 재캡처·확인했고 오류 화면은 산출물로 남기지 않았다.
